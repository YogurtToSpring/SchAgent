# CampusFlow 前后端接口契约

## 1. 基础地址

前端通过环境变量配置后端地址：

```env
VITE_API_BASE_URL=http://127.0.0.1:8080
```

默认值位于：

```text
src/api/platform.js
src/api/chat.js
src/api/files.js
```

## 2. 登录与注册

当前前端调用 `src/api/platform.js`。

### 学生登录

```text
POST /api/students/login
```

### 教师登录

```text
POST /api/teacher/login
```

### 管理员登录

```text
POST /api/admin/login
```

### 注册

根据身份调用学生、教师或管理员注册接口。注册成功后前端会再次登录并进入平台。

## 3. 平台基础数据

前端启动或登录后会调用：

```text
GET /api/students
GET /api/teacher
GET /api/course
GET /api/room
GET /api/class-stu
```

前端统一转换为：

```ts
classes: ClassItem[]
students: StudentItem[]
courses: CourseItem[]
rooms: RoomItem[]
teachers: TeacherItem[]
```

## 4. 课程与班级操作

### 调整学生班级

```text
PATCH /api/students/{id}/class
```

### 创建课程

```text
POST /api/course
```

### 给课程关联学生

```text
POST /api/course/{course_id}/students
```

这些接口目前由班级管理页面调用。

## 5. 天气

天气由前端直接调用 Open-Meteo，默认城市为武汉。

前端输出结构：

```json
{
  "city": "武汉",
  "weather": "小雨",
  "temperature": "23℃",
  "wind": "2级",
  "updatedAt": "今日 08:00"
}
```

## 6. 智能助手

### 普通对话

```text
POST /api/chat
```

请求结构：

```json
{
  "session_id": "可为空",
  "message": "用户问题",
  "user_context": {
    "user_id": "u-student-001",
    "name": "赵同学",
    "role": "student",
    "student_no": "2024001",
    "teacher_num": null,
    "class_id": "class-se-1",
    "class_ids": []
  },
  "platform_context": {
    "classes": [],
    "students": [],
    "courses": [],
    "weather": {}
  }
}
```

### 流式对话

```text
POST /api/chat/stream
```

前端支持事件：

```text
status
token
tool_call
tool_result
file_ready
error
done
```

`file_ready` 结构：

```json
{
  "name": "论持久战.md",
  "path": "论持久战.md",
  "size": 2910,
  "size_formatted": "2.9 KB",
  "modified_at": "2026-07-08T14:25:00",
  "download_url": "/api/files/论持久战.md"
}
```

前端处理逻辑：

```text
file_ready -> 文件 artifact -> 下载卡片
若没有 file_ready，但回答文本出现 .md/.pdf/.docx 等文件名，也会生成兜底下载卡片
```

## 7. 文件中心

### 文件列表

```text
GET /api/files
```

返回结构：

```json
{
  "files": [
    {
      "name": "论持久战.md",
      "size": 2910,
      "url": "/files/论持久战.md"
    }
  ]
}
```

### 文件下载

```text
GET /api/files/{file_name}
```

前端下载按钮默认访问：

```text
{VITE_API_BASE_URL}/api/files/{encodeURIComponent(file_name)}
```

后端负责代理 Agent 的：

```text
GET /files/{file_name}
```

中文文件名需要使用 UTF-8 `Content-Disposition`。

## 8. 当前前端本地模块

以下业务模块目前使用 `src/data/campusModules.js`：

```text
待办事项
成绩系统
图书馆预约
校园论坛
通知消息
系统日志
部分文件中心数据
```

建议后端接口：

```text
GET /api/todos
POST /api/todos
PATCH /api/todos/{id}

GET /api/grades
POST /api/grades/import

GET /api/library/seats
POST /api/library/reservations
GET /api/library/reservations

GET /api/forum/posts
POST /api/forum/posts
PATCH /api/forum/posts/{id}/review

GET /api/notifications
PATCH /api/notifications/{id}/read
PATCH /api/notifications/read-all

GET /api/files
GET /api/files/{file_name}
```

## 9. 助手后续工具建议

```text
create_todo
query_todos
analyze_grades
reserve_library_seat
create_forum_post
review_forum_post
publish_notification
list_user_files
```

前端不直接调用 Agent 工具，仍通过 Backend 统一暴露接口。
