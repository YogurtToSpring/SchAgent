## 1. 项目定位

这个前端不是普通聊天框，而是一个“智能体任务工作台”。

当前平台登录后主要分成四类页面：

```text
首页概览
班级管理（教师）
课表展示
智能助手
```

其中智能助手页面仍然分成三块：

```text
左侧：快捷问题
中间：聊天对话
右侧：智能体执行轨迹
```

用户在助手中输入问题后，前端会展示：

```text
1. 用户消息
2. 智能体最终回答
3. 任务执行步骤
4. 工具调用过程
5. 工具输入参数
6. 工具返回结果
7. 表格类结果
8. 参数不完整提示
9. 网络错误和重试提示
```

这正好对应项目需求里的：

```text
理解任务 -> 制定计划 -> 调用工具 -> 观察结果 -> 回答用户
```

## 5. 核心数据流

平台数据流：

```text
LoginPage 登录
  ↓
App.vue 保存 currentUser
  ↓
PlatformLayout 按角色显示导航
  ↓
DashboardPage / ClassAdminPage / SchedulePage / ChatPage 使用平台数据
```

用户发送一条消息时，完整流程是：

```text
1. 用户在 ChatInput 输入文本
2. 按 Enter 或点击发送
3. ChatInput 触发 send 事件，把文本传给 ChatPage
4. ChatPage 的 handleSend(text) 执行
5. ChatPage 先把用户消息 push 到 messages
6. ChatPage 调用 api/chat.js 里的 sendMessage，并附带 user_context 和 platform_context
7. sendMessage 调用 Mock 或真实后端
8. 后端/Mock 返回 answer、steps、tool_calls、artifacts
9. ChatPage 更新 messages、steps、toolCalls
10. ChatWindow 自动显示新消息
11. ToolTrace 自动显示执行过程
```

核心代码位置：

```text
ChatInput.vue
emit('send', value)

ChatPage.vue
<ChatInput @send="handleSend" />

ChatPage.vue
async function handleSend(text) { ... }
```

## 6. 三个核心数据结构

### 6.1 message 消息对象

消息保存在 `messages` 里。

结构示例：

```js
{
  id: '随机ID',
  role: 'assistant',
  type: 'normal',
  content: '明天上午有 **高等数学**。',
  createdAt: '08:30',
  artifacts: []
}
```

字段含义：

```text
id
每条消息的唯一标识，给 v-for 的 key 使用。

role
消息是谁发的。user 表示用户，assistant 表示智能体。

type
消息类型。normal 是普通消息，clarification 是需要用户补充信息。

content
消息正文，可以包含 Markdown。

createdAt
消息时间。

artifacts
结构化结果，例如表格。
```

### 6.2 tool_call 工具调用对象

工具调用保存在 `toolCalls` 里。

结构示例：

```js
{
  tool: 'course_query',
  label: '课程查询',
  status: 'success',
  input: {
    date: '明天',
    time_range: '上午'
  },
  output: {
    course_name: '高等数学',
    time: '08:00-09:40',
    location: '三教302'
  }
}
```

字段含义：

```text
tool
工具的程序名称，给系统识别用。

label
工具的中文显示名称，给用户看。

status
调用状态，例如 success、failed、running、fallback。

input
工具输入参数。

output
工具返回结果。
```

### 6.3 artifact 结构化结果对象

结构化结果保存在每条 assistant 消息的 `artifacts` 里。

表格示例：

```js
{
  type: 'table',
  title: '明日课程安排',
  columns: ['课程', '时间', '地点', '教师'],
  rows: [['高等数学', '08:00-09:40', '三教302', '王老师']]
}
```

这样做的好处：

```text
不要让前端从一大段文字里猜表格。
后端直接返回结构化数据，前端按 type 渲染。
以后可以扩展 chart、todo、calendar 等类型。
```

## 7. Vue 单文件组件基础

项目里每个 `.vue` 文件一般分两块：

```vue
<template>
  页面结构
</template>

<script setup>
业务逻辑
</script>
```

### 7.1 `<template>`

`template` 写 HTML 和 Vue 指令。

例如：

```vue
<button @click="submit">发送</button>
```

意思是：点击按钮时调用 `submit` 函数。

### 7.2 `<script setup>`

`script setup` 是 Vue 3 推荐写法。

普通 Vue 组件以前要写：

```js
export default {
  setup() {
    return {}
  }
}
```

现在用：

```vue
<script setup>
const text = ref('')
</script>
```

优点是更短，导入的组件和声明的变量可以直接在 template 使用。

## 8. 当前代码用到的 Vue 语法

### 8.1 文本插值 `{{ }}`

```vue
{{ message.createdAt }}
```

作用：把 JS 变量显示到页面上。

### 8.2 属性绑定 `:属性名`

```vue
<ChatInput :disabled="loading" />
```

等价于：

```vue
<ChatInput v-bind:disabled="loading" />
```

作用：把 JS 变量传给 HTML 属性或子组件 props。

### 8.3 事件绑定 `@事件名`

```vue
<button @click="submit">发送</button>
```

等价于：

```vue
<button v-on:click="submit">发送</button>
```

作用：监听事件。

### 8.4 条件渲染 `v-if`

```vue
<div v-if="error">连接失败</div>
```

作用：只有 `error` 有值时才显示这块 DOM。

### 8.5 列表渲染 `v-for`

```vue
<MessageBubble
  v-for="message in messages"
  :key="message.id"
  :message="message"
/>
```

作用：遍历 `messages` 数组，为每条消息渲染一个组件。

`key` 的作用是帮助 Vue 高效更新列表，通常要用稳定唯一值。

### 8.6 双向绑定 `v-model`

```vue
<textarea v-model="text"></textarea>
```

作用：

```text
用户输入 -> text 自动更新
代码修改 text -> 输入框内容自动更新
```

### 8.7 class 绑定

```vue
<span class="status-pill" :class="{ running: loading }">
```

意思是：

```text
永远有 status-pill 类名
如果 loading 为 true，再加 running 类名
```

数组写法：

```vue
<div :class="[message.role, message.type]">
```

意思是把 `message.role` 和 `message.type` 的值都作为 class。

例如：

```text
message.role = 'assistant'
message.type = 'clarification'
```

最终 class 相当于：

```html
<div class="assistant clarification">
```

### 8.8 表单提交修饰符 `.prevent`

```vue
<form @submit.prevent="submit">
```

普通表单提交会刷新页面。`.prevent` 会阻止默认刷新行为。

### 8.9 键盘事件修饰符

```vue
@keydown.enter.exact.prevent="submit"
@keydown.shift.enter.stop
```

含义：

```text
enter.exact
只按 Enter，不带 Shift/Ctrl/Alt 时触发。

prevent
阻止 textarea 默认换行。

shift.enter
按 Shift + Enter。

stop
阻止事件继续冒泡。
```

所以当前输入框效果是：

```text
Enter 发送
Shift + Enter 换行
```

### 8.10 `ref`

```js
const loading = ref(false)
```

`ref` 用来创建响应式数据。

在 JS 里读取或修改要写 `.value`：

```js
loading.value = true
```

在 template 里不用写 `.value`：

```vue
<ChatInput :disabled="loading" />
```

### 8.11 `computed`

```js
const currentStatus = computed(() => {
  if (loading.value) return 'running'
  if (error.value) return 'error'
  return 'idle'
})
```

`computed` 是计算属性。

它会根据依赖自动重新计算，比如 `loading` 或 `error` 变化后，`currentStatus` 自动变化。

### 8.12 `watch`

```js
watch(
  () => [props.messages.length, props.loading],
  async () => {
    await nextTick()
    windowRef.value.scrollTop = windowRef.value.scrollHeight
  }
)
```

`watch` 用来监听数据变化。

这里监听：

```text
消息数量变化
loading 状态变化
```

变化后自动滚动到底部。

### 8.13 `nextTick`

```js
await nextTick()
```

Vue 更新 DOM 不是同步立刻完成的。`nextTick` 的意思是：

```text
等页面 DOM 更新完成后，再执行后面的代码。
```

在自动滚动场景里必须等新消息渲染出来，再计算滚动高度。

### 8.14 `defineProps`

```js
const props = defineProps({
  messages: {
    type: Array,
    required: true
  }
})
```

子组件通过 `props` 接收父组件传来的数据。

父组件：

```vue
<ChatWindow :messages="messages" />
```

子组件：

```js
const props = defineProps({
  messages: Array
})
```

### 8.15 `defineEmits`

```js
const emit = defineEmits(['send'])
emit('send', value)
```

子组件通过 `emit` 通知父组件发生了某件事。

子组件：

```js
emit('send', value)
```

父组件：

```vue
<ChatInput @send="handleSend" />
```

### 8.16 动态组件 `<component :is="">`

```vue
<component :is="icon" :size="18" />
```

`icon` 是一个 computed，返回不同的图标组件。

例如：

```text
course_query -> CalendarDays
weather_query -> CloudSun
campus_route -> MapPinned
```

### 8.17 `v-html`

```vue
<div class="markdown-body" v-html="safeHtml"></div>
```

作用：把字符串当 HTML 渲染。

风险：如果直接渲染用户输入，可能有 XSS 风险。

所以代码里先用：

```js
DOMPurify.sanitize(...)
```

清理 HTML 后再渲染。

## 9. 普通 JavaScript 语法说明

### 9.1 `async / await`

```js
async function handleSend(text) {
  const response = await sendMessage(...)
}
```

表示异步流程。`await` 会等待接口返回后再继续执行。

### 9.2 解构赋值

```js
const { data } = await axios.post(...)
```

等价于：

```js
const response = await axios.post(...)
const data = response.data
```

### 9.3 模板字符串

```js
`会话 ${shortSessionId}`
```

反引号字符串可以嵌入变量。

### 9.4 展开运算符

```js
return {
  id: crypto.randomUUID(),
  role,
  type,
  content,
  ...extra
}
```

`...extra` 的意思是把 extra 对象里的字段展开合并进来。

### 9.5 可选链 `?.`

```js
props.call.tool?.includes('course')
```

如果 `tool` 不存在，不会报错，而是返回 `undefined`。

### 9.6 空值合并 `??`

```js
JSON.stringify(value ?? {}, null, 2)
```

如果 `value` 是 `null` 或 `undefined`，就用 `{}`。

### 9.7 三元表达式

```js
message.role === 'user' ? '我' : 'CampusFlow'
```

意思是：

```text
如果 role 是 user，显示“我”
否则显示“CampusFlow”
```

## 10.5 `src/App.vue`

平台化之后，`App.vue` 已经变成前端总控组件。

它负责：

```text
1. 保存当前登录用户 currentUser
2. 保存当前平台页面 activeView
3. 保存平台 Mock 数据 classes、students、courses、weather
4. 根据是否登录切换 LoginPage 和 PlatformLayout
5. 根据 activeView 显示首页、班级管理、课表或助手
6. 处理创建班级、调整学生班级、添加课程
```

核心判断：

```vue
<LoginPage v-if="!currentUser" @login="handleLogin" />

<PlatformLayout v-else>
  ...
</PlatformLayout>
```

意思是：

```text
没有 currentUser -> 显示登录页
有 currentUser -> 显示平台主界面
```

为什么把平台数据放在 App.vue？

```text
当前还没有真实后端，所以 App.vue 临时充当“前端内存数据中心”。
后续接后端时，可以把这些数据请求拆到 api 文件中。
```

```js
    return mockChatResponse(payload)

  })
```

解释：

## 12. 如何接真实后端

创建文件：


内容：

```text

```

重启前端：

```bash

```

这时 `src/api/chat.js` 会自动从 Mock 切换成真实接口：

```text
删除 .env.local 或清空 VITE_API_BASE_URL
```

## 16. 你现在最应该掌握的五件事

1. `ChatPage.vue` 是总控组件，所有核心状态都在这里。
2. 子组件通过 `props` 接收数据，通过 `emit` 把事件传回父组件。
3. `messages` 控制聊天内容，`steps` 和 `toolCalls` 控制右侧执行轨迹。
4. `api/chat.js` 现在用 Mock，后端完成后通过 `.env.local` 切换真实接口。
5. `ResultRenderer.vue` 负责把 Markdown 和结构化表格渲染成最终结果。

只要把这五点吃透，你就能看懂当前前端主体逻辑。
