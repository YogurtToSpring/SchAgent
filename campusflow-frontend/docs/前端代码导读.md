```text

```

入口文件：

```text
src/main.js

```

## 2. 顶层结构

`src/App.vue` 是前端状态中心。

它负责：

```text
恢复登录状态
登录/退出
加载平台数据
刷新天气
刷新 Agent 文件列表
维护当前页面 activeView
维护前端本地业务状态
把状态分发给各页面
处理页面 emit 出来的业务动作
```

核心状态：

```js
currentUser
activeView
classes
students
courses
rooms
weather
todos
grades
gradeSummary
librarySeats
reservations
forumPosts
notifications
files
systemLogs
todoLoading
gradeLoading
visibleNotifications
visibleFiles
```

## 3. 布局组件

文件：

```text
src/components/PlatformLayout.vue
```

职责：

```text
左侧导航
顶部栏
用户区域
主内容插槽
```

导航由 `currentUser.role` 决定。

```text
student -> 课表、成绩、图书馆、论坛等学生模块
teacher -> 教学课表、成绩录入、论坛等教师模块
admin -> 班级与课程、全校课表、成绩管理、论坛审核、管理后台
```

`App.vue` 中的 `canAccessView()` 会和导航保持一致，用于拦截不可访问页面。

页面切换不使用 vue-router，而是通过：

```js
activeView = 'dashboard'
```

并在 `App.vue` 中使用 `v-show` 控制页面显示。

## 5. 登录页面

```text

```

逻辑：

```text

调用 loginPlatformUser
```

## 6. 首页工作台

文件：

```text
src/pages/DashboardPage.vue
```

它读取：

```text
currentUser
classes
students
courses
weather
todos
notifications
reservations
grades
```

用户点击首页卡片后通过：

```js

```

让 `App.vue` 切换模块。

管理员首页不会显示“下一节课”和“今日课程”，改为平台对象和平台概况。

## 6.1 管理员班级与课程

文件：

```text
src/pages/ClassAdminPage.vue
```

结构：

```text
入口卡片
班级管理子页面
学生班级分配子页面
学生账号导入子页面
课表导入子页面
```

交互规则：

```text
所有选择操作使用搜索输入和候选结果
班级表格支持搜索、年级筛选、专业筛选、分页
学生分配通过搜索目标班级完成
账号导入逐项填写姓名、学号、班级、密码
课表导入逐项填写课程、班级、教师、时间、地点、周次、学期、学分
所有写入操作提交前使用 confirm 二次确认
```

## 6.2 课表与成绩管理

`SchedulePage.vue` 中管理员看到全校课表表格，不再切换班级课表；支持搜索和分页。

`GradesPage.vue` 中管理员按学号搜索学生成绩，选择成绩记录后确认修改；管理员页面不展示成绩分析。

## 7. 待办系统

文件：

```text
src/pages/TodoPage.vue
```

输入：

```js
props.todos
```

输出：

```js
emit('add-todo', payload)
emit('toggle-todo', todoId)
emit('delete-todo', todoId)
```

由 `App.vue` 调用后端待办接口后刷新 `todos`。助手调用待办工具成功后，`ChatPage.vue` 会 emit `todo-updated`，再由 `App.vue` 重新读取待办列表。

核心接口：

```text
POST /api/todo/add
GET /api/todo/user/{user_id}
GET /api/todo
PATCH /api/todo/{todo_id}/status
DELETE /api/todo/delete
```

## 9. 校园论坛

文件：

```text
src/pages/ForumPage.vue
```

输入：

```js
props.currentUser

```

输出：

```js
emit('add-post', post)

```

## 10. 文件中心

文件：

```text
src/pages/FileCenterPage.vue
src/api/files.js
```

点击刷新文件：

```js
emit('refresh-files')
```

`App.vue` 调用：

```js
listAgentFiles()
```

`App.vue` 会先按当前用户过滤 `visibleFiles`，文件可见性依据 `ownerId / audienceRoles / classId`。

接口：

```text
GET /api/files
```

下载链接指向：

```text
GET /api/files/{file_name}
```

## 11. 智能助手

文件：

```text
src/pages/ChatPage.vue
src/api/chat.js
```

功能：

```text
多会话

流式输出
思考过程折叠
工具轨迹折叠
```

发送消息时，前端会构造平台上下文：

```text

```

然后拼入 message，保证后端 Agent 即使只读取 message 也能知道校园数据。

## 12. 结果渲染

文件：

```text
src/components/ResultRenderer.vue
```

支持：

```text
Markdown
表格 artifact
文件 artifact
回答文本中的文件名兜底识别
```

文件名兜底识别用于这种情况：

```text
回答中出现“论持久战.md”，但后端没有发送 file_ready
```

前端会自动显示下载卡片。

## 13. API 封装

```text
src/api/platform.js
src/api/chat.js
src/api/files.js
```

原则：

```text
页面不直接写 axios
页面只通过 props 和 emit 处理业务
App.vue 负责组织跨模块状态
```

`platform.js` 当前负责：

```text
平台快照：学生、教师、班级、课程、教室、选课关系
待办：新增、查询、状态更新、删除
成绩：学生成绩、教师课程成绩、管理员全校成绩、录入/修改成绩、GPA刷新
管理员：学生账号注册导入、班级创建、学生班级调整、课程创建
```

## 14. 前端本地数据

文件：

```text
src/data/platformData.js
src/data/campusModules.js
```

`platformData.js` 放基础用户、班级、学生、课程和天气兜底数据。

`campusModules.js` 放新增业务模块数据：

```text
待办兜底
成绩兜底
图书馆
论坛
通知
文件
系统日志
```

待办和成绩已经以后端接口优先；这里的数据主要用于后端不可用时保持页面可展示。

## 15. 添加新模块的方式

1. 在 `src/pages` 新建页面。
2. 在 `App.vue` import 页面。
3. 在 `PlatformLayout.vue` 的 `navItems` 加导航项。
4. 如需本地数据，在 `campusModules.js` 增加初始数据。
5. 如需后端接口，在 `src/api` 新增封装。
6. 在 `global.css` 补页面样式。

## 16. 后续可接入的助手动作

```text
助手创建/更新待办并刷新待办页
助手分析成绩并生成学习计划
助手预约图书馆座位
助手生成论坛帖子
助手发布通知
助手生成文件并进入文件中心
```

这些动作应由后端实现工具，前端负责显示结果并刷新对应模块。
