# CampusFlow 前端代码导读

## 1. 技术栈

```text
Vue 3
Vite
Axios
Marked + DOMPurify
Lucide 图标
Dayjs
```

入口文件：

```text
src/main.js
src/App.vue
src/styles/global.css
```

## 2. 顶层结构

`src/App.vue` 是前端状态中心。

它负责：

```text
恢复登录状态
登录/退出
加载平台数据
刷新天气
刷新 Agent 文件列表
维护当前页面 activeView
维护前端本地业务状态
把状态分发给各页面
处理页面 emit 出来的业务动作
```

核心状态：

```js
currentUser
activeView
classes
students
courses
rooms
weather
todos
grades
librarySeats
reservations
forumPosts
notifications
files
systemLogs
```

## 3. 布局组件

文件：

```text
src/components/PlatformLayout.vue
```

职责：

```text
左侧导航
顶部栏
用户区域
主内容插槽
```

导航由 `currentUser.role` 决定。

```text
student -> 学生常用模块
teacher -> 增加班级管理
admin -> 增加管理后台
```

页面切换不使用 vue-router，而是通过：

```js
activeView = 'dashboard'
```

并在 `App.vue` 中使用 `v-show` 控制页面显示。

## 5. 登录页面

文件：

```text
src/pages/LoginPage.vue
```

逻辑：

```text
选择身份
输入账号密码
调用 loginPlatformUser
失败时尝试本地兜底账号
成功后 emit('login', user)
```

注册逻辑调用 `registerPlatformUser`。

## 6. 首页工作台

文件：

```text
src/pages/DashboardPage.vue
```

它读取：

```text
currentUser
classes
students
courses
weather
todos
notifications
reservations
grades
```

用户点击首页卡片后通过：

```js
emit('navigate', 'todos')
```

让 `App.vue` 切换模块。

## 7. 待办系统

文件：

```text
src/pages/TodoPage.vue
```

输入：

```js
props.todos
```

输出：

```js
emit('add-todo', payload)
emit('toggle-todo', todoId)
```

由 `App.vue` 实际修改 `todos`。

## 8. 图书馆预约

文件：

```text
src/pages/LibraryPage.vue
```

输入：

```js
props.seats
props.reservations
```

输出：

```js
emit('reserve-seat', reservation)
emit('add-todo', todo)
```

确认预约后会同步创建一条图书馆待办。

## 9. 校园论坛

文件：

```text
src/pages/ForumPage.vue
```

输入：

```js
props.currentUser
props.posts
```

输出：

```js
emit('add-post', post)
emit('review-post', postId)
```

学生发帖进入审核状态；教师和管理员发帖直接发布；管理员可审核待审内容。

## 10. 文件中心

文件：

```text
src/pages/FileCenterPage.vue
src/api/files.js
```

点击刷新文件：

```js
emit('refresh-files')
```

`App.vue` 调用：

```js
listAgentFiles()
```

接口：

```text
GET /api/files
```

下载链接指向：

```text
GET /api/files/{file_name}
```

## 11. 智能助手

文件：

```text
src/pages/ChatPage.vue
src/api/chat.js
```

功能：

```text
多会话
会话改名
流式输出
思考过程折叠
工具轨迹折叠
文件下载卡片
快捷问题随机生成
```

发送消息时，前端会构造平台上下文：

```text
当前用户
班级
学生
课程
天气
```

然后拼入 message，保证后端 Agent 即使只读取 message 也能知道校园数据。

## 12. 结果渲染

文件：

```text
src/components/ResultRenderer.vue
```

支持：

```text
Markdown
表格 artifact
文件 artifact
回答文本中的文件名兜底识别
```

文件名兜底识别用于这种情况：

```text
回答中出现“论持久战.md”，但后端没有发送 file_ready
```

前端会自动显示下载卡片。

## 13. API 封装

```text
src/api/platform.js
src/api/chat.js
src/api/files.js
```

原则：

```text
页面不直接写 axios
页面只通过 props 和 emit 处理业务
App.vue 负责组织跨模块状态
```

## 14. 前端本地数据

文件：

```text
src/data/platformData.js
src/data/campusModules.js
```

`platformData.js` 放基础用户、班级、学生、课程和天气兜底数据。

`campusModules.js` 放新增业务模块数据：

```text
待办
成绩
图书馆
论坛
通知
文件
系统日志
```

## 15. 添加新模块的方式

1. 在 `src/pages` 新建页面。
2. 在 `App.vue` import 页面。
3. 在 `PlatformLayout.vue` 的 `navItems` 加导航项。
4. 如需本地数据，在 `campusModules.js` 增加初始数据。
5. 如需后端接口，在 `src/api` 新增封装。
6. 在 `global.css` 补页面样式。

## 16. 后续可接入的助手动作

```text
助手创建待办
助手分析成绩并生成学习计划
助手预约图书馆座位
助手生成论坛帖子
助手发布通知
助手生成文件并进入文件中心
```

这些动作应由后端实现工具，前端负责显示结果并刷新对应模块。
